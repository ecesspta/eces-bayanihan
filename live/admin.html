ECES Bayanihan · Admin

For the SPTA chairperson or the person who runs the app. The admin key is typed here and sent only to your own server. Never share it or save it in a file.

Start the real record

This replaces the fictional rehearsal with an empty school record and the officers below. It is refused once real data exists. One officer per line, as role: Full Name. Roles: head, chair, vice, secretary, treasurer, collector.

Add the HPTA presidents

One section per line, as Grade · Section | President's name, for example Grade 1 · Ramos | Full Name. For kindergarten write Kindergarten · Biala A.M. | Full Name. Running it again only adds sections that are missing.

Opening balance and finished project

Use the treasurer's paper. The balance is one figure on one date and can only be set before any money is recorded in the app. The finished project is shown as Completed, with no vote, no signatures and no SPTA money used. Fill in only what you need.

New code for one officer

For a lost phone or forgotten sign-in, or to add the collecting officer later. Add the name only for a new officer.

Project already voted on

For a project the officers already voted on and the School Head already approved on paper. It goes straight to a draft resolution, so the secretary can release it and the officers can sign in the app. The vote needs at least 51% yes. Add one project at a time.

Who is on the app

Everyone with an account, and whether they can sign in. It shows no passwords, invite codes or private messages. Mobile numbers are partly hidden.
